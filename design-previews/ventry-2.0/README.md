# Ventry 2.0 — визуальный прототип

**Статус:** предложение для визуального согласования. **Не production и не готовый редизайн.**

Этот вариант проверяет структуру из `docs/VENTRY-DESIGN-CONCEPT-2.0.md`:

- фирменная AMOLED Editorial палитра, SVG-логотип Ventry, локальные шрифты Golos Text;
- главная с полноценными `#about`, `#method`, `#projects`, `#contact` вместо скрытых модальных разделов;
- один настоящий публично описанный проект «Расчёт» со статусом «В разработке»;
- видимые ссылки на опубликованные продуктовую и юридические страницы;
- мобильное меню и состояния действий (mailto, копирование), минимум JavaScript.

## Как смотреть

Откройте `index.html` в браузере — в файле встроены CSS, JS, существующие шрифты, исходный SVG-логотип и опубликованная иллюстрация «Расчёта». Для самостоятельного тестирования скриншоты по нескольким размерам лежат в артефактах специального GitHub Actions workflow `Ventry 2.0 design preview`.

## Что не входит

Макет не заменяет главную сайта и не изменяет `site/`. Фактическая работа приложения «Расчёт», юридические требования, домен, инфраструктура, формы и интеграции не реализованы. Фирменный адрес электронной почты не выдуман. Контент разделов — рабочие формулировки для утверждения.

## Критерии предварительного просмотра

- Экран телефона показывает содержательный первый экран без большого пустого поля и естественный переход к «О Ventry».
- На 320/390/768/1440 px нет горизонтального переполнения, текст не перекрыт фирменной графикой, контент на каждой ширине читаем.
- Меню работает и закрывается после перехода, `#about`, `#method`, `#projects`, `#contact` ведут к открытым разделам.
- Используются исходные бренд и изображение, без вымышленных проектов, метрик и отзывов.
- На следующем этапе нужно проверить скриншоты, оценить композицию и после замечаний отдельно разрешить реализацию в `site/`.

**Пока не одобрено:** содержание hero/заголовков, вертикальная плотность, оформление раздела «Расчёт», само решение заменить модальные окна на обычные секции.
