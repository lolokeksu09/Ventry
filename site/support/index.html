Частые вопросы

Как получить Android-приложение?

Напишите Ventry и уточните доступность сборки и условия получения. Запросить Android-версию.

Можно ли пользоваться демо для реального учёта?

Нет, это только интерактивный пример. Данные вымышлены, изменения сбрасываются. Инструкция по демо.

Почему записи исчезли после обновления страницы?

Для демо это нормальное поведение. Реальные записи в отдельном Android-приложении требуют отдельной диагностики. Не очищайте данные и не переустанавливайте приложение до проверки резервных копий.

Как передать информацию об ошибке?

Опишите версию приложения, модель устройства, последовательность действий и ожидаемый результат. Не отправляйте имена клиентов, телефоны, пароли и резервные копии.

Обращение в Ventry

Подготовьте письмо без регистрации. Оно будет отправлено только вами из вашего почтового приложения.
