Данные и копии

Копия — это способ сохранить записи при смене устройства или очистке браузера.

Настройки магазина

Крупный режим увеличивает кнопки, имена и суммы. Настройки сохраняются на этом устройстве.

Сохранить записи

JSON содержит клиентов и полную историю. CSV подходит для таблиц. Для хранения вне устройства используйте копию с паролем.

Восстановить книгу

Импорт полностью заменит текущую книгу в выбранном режиме. Перед заменой скачайте резервную копию. Файл проверяется до сохранения.

Подходят обычные и защищённые JSON-копии. Данные примера и ваша книга хранятся отдельно.

Автоматические копии

До пяти последних версий книги в этом браузере. Скачайте JSON и храните его отдельно: при очистке данных браузера локальные копии тоже пропадут.
