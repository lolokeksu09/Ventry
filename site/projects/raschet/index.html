О проекте

Можно уже пользоваться «Расчётом»?

Пока нет. Приложение находится в разработке. Эта страница знакомит с его назначением и не принимает данные о долгах.

Это сайт для учёта долгов?

Ventry — сайт проекта и каталог цифровых продуктов. «Расчёт» задуман как отдельное приложение.

Когда появится приложение?

Дата публичного запуска пока не объявлена. Актуальный статус проекта будет указан на этой странице.
