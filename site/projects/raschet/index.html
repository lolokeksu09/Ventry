Вопросы о «Расчёте»

Можно уже пользоваться «Расчётом»?

На сайте доступно интерактивное демо. Для уточнения доступности и условий получения Android-приложения свяжитесь с Ventry.

На каких устройствах работает приложение?

Основное приложение предназначено для Android. Демо открывается в браузере телефона, планшета или компьютера.

Сохраняются ли данные демо?

Нет. Изменения существуют только до перезагрузки страницы. Демо не принимает резервные копии и не предназначено для реального учёта.
