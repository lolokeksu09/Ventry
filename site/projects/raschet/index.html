Вопросы о «Расчёте»

Можно уже пользоваться «Расчётом»?

Демо доступно без входа и использует вымышленные записи. Для общей книги нужна учётная запись пилота. Чтобы подключиться, напишите Ventry.

На каких устройствах работает приложение?

Общая книга открывается в браузере телефона, планшета или компьютера. В локальной версии есть крупный режим для планшета.

Как перенести записи на другое устройство?

Для общей книги войдите в тот же аккаунт на другом устройстве. Для локальной книги используйте «Данные и копии». Перенос из локальной книги в общую пока недоступен.
