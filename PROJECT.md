# Ventry — карточка проекта

## Подтверждённое назначение

Ventry — сайт компании и каталог цифровых проектов. Первый публично упомянутый проект — «Расчёт»; отдельное приложение ещё разрабатывается. На текущем этапе сайт не выполняет долговые расчёты и не содержит платёжной функциональности.

## Стек и целевая среда

- Статические HTML/CSS/JavaScript, Caddy, Docker Compose; Selectel VDS.
- Источники истины: `site/`, `compose.yaml`, `deploy/Caddyfile`, `.github/workflows/deploy.yml`.
- Развёртывание: `main` → GitHub Actions → ограниченная SSH-команда → контейнер `ventry-web-1`.
- Публичный HTTPS: временное имя `135-106-227-179.sslip.io`. Собственный домен не согласован.

## Критерий готовности текущей задачи

1. `https://135-106-227-179.sslip.io/` обслуживается по публично доверенному HTTPS, без обхода проверки сертификата.
2. `https://135-106-227-179.sslip.io/healthz` возвращает `ok`; главная страница содержит Ventry.
3. `http://135.106.227.179/` перенаправляется на HTTPS с кодом 308.
4. Несуществующий путь возвращает 404; SSH-секреты не попадают в исходники.
5. Результат подтверждён на опубликованной версии в GitHub Actions; при сбое статус остаётся неуспешным.

## Область, которую нельзя повредить

- Не изменять другие Docker-проекты, порты сервисов или чужие файлы VDS.
- Не менять содержимое `/opt/ventry/.env` и постоянные Docker-тома.
- Не превращать карточку «Расчёт» в фиктивно работающий продукт.
- Секреты и приватные ключи не записывать в Git.

## Открытое решение

Приобретение/предоставление собственного домена, настройка его DNS A-записи и замена временного sslip.io имени. При смене домена синхронно обновить smoke-check, SEO-метаданные и документацию; окончательное удаление старого адреса — только по отдельному решению.
