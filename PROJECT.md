# Ventry — карточка проекта

## Подтверждённое назначение

Ventry — корпоративный сайт и каталог цифровых продуктов. «Расчёт» — первый публичный проект каталога. Коммерческий продукт — отдельное Android-приложение (APK); сайт представляет его назначение и предоставляет интерактивное демо с вымышленными данными.

**Уточнение владельца 26.11.2026:** веб-демо не является отдельным рабочим продуктом. Ведение реальной клиентской базы, серверная книга, синхронизация и масштабирование веб-хранилища не входят в Ventry 2.0.

Кандидат 2.0 открывает только вымышленный пример в памяти вкладки; прежние локальные записи доступны исключительно для выгрузки, без автоматического удаления. Приёмка кандидата и публикация ещё не подтверждены. Статус Android-релиза, цена и коммерческие условия подтверждаются отдельно по репозиторию продукта.

## Стек и целевая среда

- Статические HTML/CSS/JavaScript, Caddy, Docker Compose; Selectel VDS.
- Источники истины: `site/`, `compose.yaml`, `deploy/Caddyfile`, `.github/workflows/deploy.yml`.
- Развёртывание: `main` → GitHub Actions → ограниченная SSH-команда → контейнер `ventry-web-1`.
- Основной публичный HTTPS: `ventrylab.top`; `135-106-227-179.sslip.io` обслуживается как технический адрес. Оба закреплены в `deploy/Caddyfile`.

## Защищённые критерии поставки

1. `https://ventrylab.top/` обслуживается по публично доверенному HTTPS, без обхода проверки сертификата.
2. `https://ventrylab.top/healthz` возвращает `ok`; главная страница содержит Ventry. Старый технический HTTPS-хост продолжает отвечать.
3. `http://135.106.227.179/` перенаправляется на HTTPS с кодом 308.
4. Несуществующий путь возвращает 404; SSH-секреты не попадают в исходники.
5. Результат подтверждён на опубликованной версии в GitHub Actions; при сбое статус остаётся неуспешным.

## Область, которую нельзя повредить

- Не изменять другие Docker-проекты, порты сервисов или чужие файлы VDS.
- Не менять содержимое `/opt/ventry/.env` и постоянные Docker-тома.
- Не превращать карточку «Расчёт» в фиктивно работающий продукт.
- Секреты и приватные ключи не записывать в Git.

## Текущая разработка

Аудит и реестр приёмки: [docs/AUDIT.md](docs/AUDIT.md). Применяется предоставленный владельцем Project Workflow Standard v1.0. Текущая задача явно разрешает изменения в GitHub и публикацию через существующий SSH-деплой.

Каталог ведёт на `/projects/raschet/`; JavaScript не требуется для чтения, переходов и FAQ. Копирование ссылки и краткий диалог — дополнительные возможности. Назначение долговой книги не означает готовность приложения.

Команды проверок и поставки: [README.md](README.md), [workflow](.github/workflows/deploy.yml). L1 — синтаксис и внутренние ссылки, L2/L3 — действия в браузере, L4 — validate и приёмка кандидата с явно указанными ограничениями среды, L5 — SHA и файлы реальной HTTPS-поставки.

## Открытое решение

Домен `ventrylab.top` закреплён как основной. Старый `sslip.io` адрес пока сохраняется; его окончательное удаление — только по отдельному решению. Старые адреса отдельных приложений и входа не мигрируются этой задачей.

## Визуальное направление

Главная представляет компанию Ventry. На первом экране главные элементы — название, описание деятельности и кнопка перехода к каталогу. Каталог размещён в отдельном разделе `/#projects`. Знак Ventry и локальный Golos Text формируют оформление компании. У главной — отдельная обложка для предпросмотра ссылки.

Иллюстрация открытой долговой книги и пример частичного возврата размещены на странице «Расчёта». В каталоге изображение используется как небольшая миниатюра проекта. История изученных подходов приведена в [исследовании дизайна](docs/DESIGN-RESEARCH.md). Приёмка описана в [аудите](docs/AUDIT.md).
