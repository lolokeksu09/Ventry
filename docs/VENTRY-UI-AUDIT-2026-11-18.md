# Ventry — аудит и улучшение всех страниц, 18.11.2026

## Область проверки

Официальные страницы: `/`, `/projects/raschet/`, `/legal/`, `/privacy/`. На главной: вкладки «Компания», «Подход», «Проекты», «Контакты», мобильное меню, футер и прямые ссылки с фрагментами. Дизайн сохраняет утверждённые AMOLED-цвета и фирменный SVG.

## Зафиксированные проблемы и исправления

| Приоритет | Наблюдение | Исправление |
| --- | --- | --- |
| P1 | Во вкладке «Проекты» на пользовательском скриншоте вместо фотографии виден однотонный квадрат; исходный `img` имел `loading=lazy` внутри изначально скрытой панели | Смена на `raschet-ledger-small.webp`, `loading=eager`, preload ресурса; браузерная проверка натуральной ширины изображения |
| P1 | Главная обновилась до AMOLED, остальные три страницы оставались в старом светлом дизайне | Единый `site/inner-pages.css` поверх существующей базовой таблицы; строгая журнальная композиция, контраст, мобильное меню, без правок фактов и юридических обязательств |
| P1 | Переключение каждой вкладки добавляло запись History; кнопка «Назад» могла перебирать давно закрытые панели | Для открытого диалога применяется `replaceState`, при первом открытии — `pushState`. Клавиша Escape обрабатывается через нативное событие `cancel`. |
| P2 | Футер главной на высоком телефоне висел над большим пустым нижним пространством | Компоновка `main` по доступной высоте с футером у нижней границы viewport |
| P2 | Правовая информация и политика не имели навигации по длинным разделам | Добавлены компактные внутренние ссылки на существующие `h2[id]`; тексты, правовой статус, даты и политика не заменены |
| P2 | На странице проекта имелся текст в повелительном наклонении, который можно прочитать как обещание работающего продукта | Разделён проектируемый сценарий и существующий продукт; пример учёта подписан как сценарий |
| P2 | Уведомление о копировании ссылки на странице проекта оставалось навсегда | Кратковременное сообщение и сброс при повторном нажатии; резервный выбор URL сохранён |
| P2 | Без JavaScript содержание модального интерфейса недоступно | `noscript` показывает минимальное описание Ventry, ссылку на «Расчёт» и email |

## Регрессионная проверка

`tests/visual-pages.py` запускается в GitHub Actions с Chrome на ширинах 320, 390, 768, 1440 и проверяет все четыре маршрута, горизонтальное переполнение, загрузку фото, работу FAQ, мобильное меню, ссылки оглавления, историю модальных вкладок, прямой `/#projects` и кнопку «Назад». Снимки сохраняются в артефакт Actions. Браузерное тестирование не заменяет визуальный контроль на реальном Lenovo. Проверка Caddy, маршрутов и безопасности остаётся в существующем deploy workflow.

## Публикация

PR → два зелёных CI (браузерный и проверка деплоя) → squash merge в `main` → автоматическая публикация через GitHub Actions → проверка фактического production run.
