# Ventry Admin

Приватный клиент Ventry Delivery для работы с проектами, подписками, оплатами и выдачей APK. Kotlin, Jetpack Compose, AndroidViewModel и StateFlow. Текущая версия в исходниках — `0.8.0-alpha.1`. Развёрнутую ревизию API и установленный APK сверять отдельно по [статусу экосистемы](ECOSYSTEM-STATUS.md).

## Подключение и сеанс

- При первом подключении указать приватный HTTPS origin, ключ администратора и, если требуется, сертификат CA. Для доступа с телефона использовать настроенный частный канал из [инструкции Delivery](VENTRY-DELIVERY-PRIVATE-DEPLOY.md). Системная проверка имени хоста сохраняется. HTTP разрешён только для debug loopback.
- Сохранение подключения включается явно. После успешного входа и загрузки проектов Android Keystore защищает сохранённый ключ и параметры подключения зашифрованным файлом с подтверждением учётными данными телефона. При смене CA или недоступном ключе возможен ручной вход.
- Серверная сессия действует 15 минут. Клиент блокирует экран через 14 минут. Выход отзывает сессию и сохраняет подключение, если оно было запомнено. Действие «Забыть подключение» удаляет локальный файл и ключ, сохраняя серверные данные и запись ожидающей оплаты.

## Подписки и выдача

- Поиск и очередь продлений используют серверный список проекта. Для старого API предусмотрен явно обозначенный режим совместимости. Локальное имя можно вручную перенести в пустую серверную карточку. Изменения имени используют ревизию карточки и обрабатывают конфликт.
- История содержит подтверждённые платные события с пагинацией. Итог проекта берётся из серверного агрегата за 7, 30, 90 дней или всё время. Подтверждение оплаты в Admin не является фискальным чеком. После обрыва сети повтор подтверждения использует прежний ID события и параметры.
- Выдача APK привязана к ранее показанному SHA-256 через `expected_release_sha256`. При смене активного APK оператор должен снова проверить карточку версии. На VDS сначала обновляется Delivery, затем Admin. Порядок — в [эксплуатации](DELIVERY-OPERATIONS.md).

| Приватный API | Контракт |
|---|---|
| `GET/POST /api/v1/customers/{id}` | Имя и ревизия. Конфликт правки возвращает `409`. |
| `GET /api/v1/projects/{code}/desk` | Поиск и фильтр по проекту, пагинация через `after`. После мутации список обновляется. |
| `GET /api/v1/projects/{code}/revenue` | Положительные подтверждённые начисления за скользящий период. Без `days` берётся весь срок. |
| `GET /api/v1/subscriptions/{id}/payments` | Платные события подписки с курсором `after`. |

## Сборка и проверка

```bash
gradle -p admin-android testDebugUnitTest lintDebug assembleDebug --no-daemon
```

Debug APK находится в `admin-android/app/build/outputs/apk/debug/app-debug.apk`. [CI Admin](../.github/workflows/ventry-admin-android.yml) запускает изолированную интеграцию с тестовой PostgreSQL и Delivery. Подтверждение сохранения подключения, смена учётных данных и работу на приватном HTTPS проверить на физическом Android с тестовыми данными.

[История ранних итераций Admin](https://github.com/lolokeksu09/Ventry/blob/a6878a804f3773aa226ae725691df0b6d0789589/docs/VENTRY-ADMIN-ANDROID.md).
