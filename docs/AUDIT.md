## Выполненные проверки до поставки

- `node --check site/app.js` — успех.
- `python3 tools/verify-site.py` — успех: 2 страницы, внутренние пути, фрагменты, ресурсы, canonical URL и один h1 на страницу.
- Негативная проверка этого инструмента: временная битая ссылка и отсутствующий фрагмент отклонены; исходник восстановлен.
- `bash -n deploy/ventry-github-status` — успех, сам скрипт не изменён.
- `git diff --check` — успех.
- Docker отсутствует в локальной среде: Compose и Caddy проверяются реальными jobs в GitHub Actions перед merge и публикацией.
- Локальный preview недоступен отдельному облачному браузеру (`ERR_CONNECTION_REFUSED`). Это не проверка вёрстки. Браузерная приёмка новой версии проводится на реальном HTTPS после поставки; её результат нужно дописать ниже.

## Точка продолжения

Дождаться validate в PR, слить проверенный кандидат, проверить production workflow и `/version.json`, затем выполнить браузерную приёмку и обновить этот документ. Любой сбой приёмки исправлять отдельным проверенным патчем.
