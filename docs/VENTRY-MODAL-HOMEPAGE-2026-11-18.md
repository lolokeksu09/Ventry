# Ventry — главная с модальными разделами

Дата: 18 ноября 2026

## Решение

Вместо длинной линейной главной по запросу владельца разделы **Компания, Подход, Проекты и Контакты** перенесены в один нативный HTML `<dialog>` с четырьмя переключаемыми панелями. На самой главной остаются компактная обложка Ventry, горизонтальная навигация и правовой футер. Действующие материалы, контакты, SVG-логотип, палитра и ссылки сохранены.

## Взаимодействия

- Вкладки `#about`, `#method`, `#projects`, `#contact` открывают модальное окно.
- Между разделами можно переключаться внутри окна без закрытия.
- Закрытие: кнопка ×, Escape, нажатие на затемнённую область.
- На мобильном переход из меню автоматически его закрывает.
- Ссылки вида `/#projects` открывают нужную вкладку при прямом переходе.
- URL обновляется через History API, активные вкладки помечаются `aria-current="location"`.
- В окне работает аккордеон принципов и копирование адреса `ventrybusinesswork@gmail.com`.
- Ссылка «Расчёт» ведёт на самостоятельный `/projects/raschet/`, подтверждённого статуса готовности нет.
- При закрытии окна адрес очищается и фокус возвращается к элементу, открывшему окно.

## Совместимость

CSP Caddy не изменяется: `site/home-company.css` и `site/company-nav.js` подключены как локальные файлы без inline CSS/JS. HTML остаётся доступным поисковым системам в исходной разметке, хотя содержимое помещено внутрь диалога. JS необходим для открытия разделов; при выключенном JavaScript модальные разделы не открываются — ограничение этой версии.

## Проверка и публикация

CI `Ventry modal homepage visual QA` тестирует шесть viewport (320, 360, 390, 430, 768, 1440), прямые URL с hash, навигацию, модальные вкладки, закрытие и копирование почты, проверяет отсутствие горизонтального переполнения, а также генерирует автономный HTML для просмотра. Merge в `main` автоматически запускает production workflow — публикацию делать только после подтверждённых проверок.
