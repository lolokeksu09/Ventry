# Точка продолжения Ventry (шаблон)

Не активный журнал. Используй один текущий снимок, подробную историю оставляй в PR и Git.

| Поле | Текущее состояние |
| --- | --- |
| Цель, критерий и ограничения | Не заполнено |
| Репозиторий, ветка, SHA, diff | Не зафиксированы |
| Реализовано / сохранено | Не заполнено |
| Опубликовано / реальный SHA сайта | Не подтверждено |
| Проверки и ссылки на evidence | Не заполнено |
| Остаток, блокеры, EXC-ID и сроки | Не заполнено |
| Одно следующее действие и результат | Не определено |

При продолжении перепроверь текущий HEAD, CI, фактический деплой и возраст отчётов. Незавершённый старый чекбокс не может считаться доказательством, будущий SHA нельзя предсказать. Не переносить секреты.
