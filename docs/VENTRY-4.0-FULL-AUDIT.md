## Критерии приёмки текущего кандидата

1. Единый HEADER, footer и skip-link: генераторы, проверка исходников, 13 маршрутов в пяти viewport, текущие девять ширин, no-JS, клавиатура и снимки.
2. Демонстрация: отмена пробной оплаты скрывает результат, возврат из персональной статистики к правильному экрану, создание карточек и прежние сценарии не ломаются; legacy localStorage остаётся без изменений.
3. Caddy и source guards без ослабления CSP, все существующие URL, ресурсный бюджет, Lighthouse без автоматических замечаний, отдельно сравнить CLS.
4. Production подтверждается только после merge и успешного deploy по точному SHA.

Ограничения: полный ручной тест всех состояний на физическом Android, screen reader, внешний pentest, прямой доступ к VDS и юридическая/коммерческая приёмка не выполнены. Кандидат текущего патча ещё требует CI и production. Не выдавать этот отчёт за завершение всех пунктов.
